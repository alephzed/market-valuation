# Reimplement the Valuation Model in Java, not a polyglot Python component

The Valuation Model is reimplemented entirely in Java: Calibration uses an ordinary-least-squares fit (Apache Commons Math), the Shiller Data is parsed with Apache POI, and scraping uses Jsoup. We rejected keeping a Python component (e.g. a Python Lambda for training) because the "model" is trivial - four Coefficients and linear arithmetic, not real machine learning - so a second runtime would add cross-language operational complexity for no analytical benefit, and a single-language Java system is the explicit goal.

## Consequences

- The scikit-learn `LinearRegression` and the pickled model artifact are dropped entirely; Coefficients are persisted as a Postgres row and regenerated by Calibration.
- If the Model ever grows genuine ML sophistication, this decision should be revisited - the polyglot option becomes justified at that point.
